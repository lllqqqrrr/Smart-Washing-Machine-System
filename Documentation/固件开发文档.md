## 编译与烧录

### 准备工作
1. 安装 Keil MDK (v5.36+)
2. 安装 STM32F1xx 支持包
3. 安装 ST-Link 驱动程序

### 编译步骤
1. 打开 `Firmware/Project/WashingMachine.uvprojx`
2. 菜单: Project → Build → Rebuild
3. 编译完成后生成 `.hex` 或 `.bin` 文件

### 烧录步骤
1. 连接 ST-Link 调试器
2. 菜单: Flash → Download
3. 选择输出文件并下载
4. 下载完成后自动运行

## 各模块说明

### 1. main.c - 主程序
- 系统初始化
- 主循环管理
- 传感器数据处理
- 状态机管理

### 2. system_init.c - 系统初始化
- GPIO 端口配置
- UART/SPI 通信初始化
- 定时器配置
- ADC 转换器配置
- 外部中断配置
- 优先级分配

### 3. algorithm.c - 自适应算法
- 根据衣物重量自动调整洗涤时间
- 根据浊度自动调整漂洗次数
- PID 温度控制算法
- 工作模式参数管理

### 4. safety.c - 安全保护
- 门状态检测
- 水位过高/过低报警
- 温度过高报警
- 电机过载检测
- 漏水检测
- 综合故障处理

### 5. motor.c - 电机控制
- 启动/停止洗涤电机
- 脱水电机 PWM 控制
- 转速监测
- 加速/减速曲线

### 6. valve.c - 阀门控制
- 进水阀开/关
- 排水阀开/关
- 漂洗阶段的阀门切换

### 7. sensor.c - 传感器读取
- 温度传感器(DS18B20) 读取
- 水位传感器采样
- 重量传感器读取
- 浊度传感器读取
- 门开关状态检测
- 漏水传感器检测

### 8. lcd.c - LCD 显示
- LCD1602 或 OLED 驱动
- 显示工作模式
- 显示当前状态
- 显示剩余时间
- 显示错误信息
- 显示参数设置界面

### 9. bt.c - 蓝牙模块
- HC-05 配置初始化
- 蓝牙数据接收处理
- 命令解析
- 状态数据发送
- APP 通信协议实现

## 中断优先级

| 中断源 | 优先级 | 频率 | 说明 |
|------|------|------|------|
| 门开关(EXTI1) | 0 | - | 最高,紧急停止 |
| 水位过高(EXTI) | 1 | - | 关闭进水阀 |
| Timer2(采样) | 2 | 1000Hz | 传感器采样 |
| UART 接收 | 3 | 变 | 接收上位机命令 |
| Timer4(计时) | 4 | 100Hz | 系统计时 |

## 工作模式流程

### 启动流程
```
上电
  ↓
系统初始化(GPIO/Timer/ADC/中断)
  ↓
检测门状态
  ↓
等待用户选择模式
  ↓
计算洗涤参数
  ↓
开始工作
```

### 洗涤流程
```
开始
  ↓
打开进水阀 → 监测水位达到设定值 → 关闭进水阀
  ↓
加热(如需要) → 达到目标温度 → 维持温度
  ↓
启动洗涤电机 → 运行设定时间 → 停止电机
  ↓
排水 → 等待水排空
  ↓
漂洗(循环执行):
  ├→ 进水
  ├→ 轻柔搅动
  ├→ 排水
  └→ 判断是否继续漂洗
  ↓
最后脱水:
  ├→ 打开排水阀
  ├→ 启动脱水电机
  ├→ 逐步加速到最高转速
  ├→ 维持一段时间
  └→ 逐步减速停止
  ↓
完成
  ├→ 蜂鸣器提示
  ├→ 显示完成信息
  └→ 等待取衣
```

## 通信协议

### 串口通信(PC 端)
- 波特率: 9600 bps
- 数据格式: JSON
- 发送周期: 1 秒

**示例:**
```json
{"state":1, "temp":45.5, "water":75, "weight":2500, "time":1234, "error":0}
```

### 蓝牙通信(APP 端)
- 波特率: 9600 bps
- 协议: 二进制帧格式
- 包格式: [STX][CMD][LEN][DATA][CHK][ETX]

## 调试与故障排除

### 常见问题

1. **编译错误: undefined reference to '...'
   - 检查所有 `.c` 文件是否添加到工程
   - 检查头文件包含路径

2. **烧录失败
   - 检查 ST-Link 连接
   - 检查芯片选择是否正确
   - 尝试擦除整个芯片后重新烧录

3. **程序运行异常
   - 使用调试器逐步运行
   - 查看寄存器和内存值
   - 检查优先级和中断配置

4. **传感器读值不稳定
   - 增加采样次数(软件滤波)
   - 检查电路连接
   - 添加硬件滤波电容

### 调试工具
- Keil MDK 内置调试器
- 串口监视器查看日志
- 逻辑分析仪测试信号
