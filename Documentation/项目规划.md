# 智能洗衣机系统 - 详细规划文档

## 1. 项目概述

### 1.1 项目背景
当前洗衣机行业发展趋势为智能化、自适应、安全可靠。本项目旨在设计一个具有完整自动控制功能的智能洗衣机系统，通过多种传感器实时获取环境与机器状态信息，由STM32微处理器进行决策与控制，实现全自动洗涤、智能自适应、多重安全保护。

### 1.2 设计目标
- **全自动**：完整的洗涤程序自动执行，用户只需选择模式
- **自适应**：根据衣物重量、污染度等自动调节参数
- **高安全**：多重安全保护机制，防止各类故障
- **易操作**：直观的人机交互，简单易用
- **远程控制**：支持手机APP远程监控与控制
- **数据记录**：完整的洗涤数据存储与查询

### 1.3 创新点
1. 浊度传感器自适应漂洗次数
2. 重量传感器智能控制用水量
3. 蓝牙APP远程监控
4. 水浸传感器漏水报警
5. 自定义模式保存与查询

### 2.2 功能模块划分

#### 传感器模块
```
传感器输入
├── 水位传感器 (3个) → ADC通道0,1,2
├── 温度传感器 (DS18B20) → GPIO PA0 (1-Wire)
├── 重量传感器 → ADC通道3 (HX711)
├── 门开关 → GPIO PA1 (中断)
├── 浊度传感器 → ADC通道4
├── 水浸传感器 → GPIO PA2
└── 电流检测 → ADC通道5
```

#### 执行器模块
```
执行器输出
├── 洗涤电机 → GPIO PB0 (继电器控制)
├── 脱水电机 → GPIO PB1 (PWM控制)
├── 进水阀 → GPIO PB2 (继电器控制)
├── 排水阀 → GPIO PB3 (继电器控制)
├── 加热管 → GPIO PB4 (继电器控制)
├── 蜂鸣器 → GPIO PB5 (PWM控制)
├── 红色LED → GPIO PB6
├── 绿色LED → GPIO PB7
└── 黄色LED → GPIO PB8
```

#### 通信模块
```
通信接口
├── UART1 → PC上位机 (9600 bps)
├── UART2 → 蓝牙模块HC-05 (9600 bps)
└── I2C → EEPROM (400kHz)
```

### 3.4 工作模式设计

#### 标准洗涤流程
```
启动
  ↓
门检查 (门必须关闭)
  ↓
水位检查
  ↓
进水阶段
  ├─ 打开进水阀
  ├─ 监测水位
  ├─ 水位到达预设值时关闭进水阀
  └─ 确认进水完成
  ↓
加热阶段 (如需要)
  ├─ 打开加热管
  ├─ 监测水温
  ├─ 达到设定温度时关闭加热管
  └─ 保持温度稳定
  ↓
洗涤阶段
  ├─ 启动洗涤电机
  ├─ 运行设定时间
  ├─ 监测电流(过载保护)
  └─ 停止电机
  ↓
漂洗阶段 (循环执行)
  ├─ 排水
  ├─ 进水
  ├─ 轻柔搅动
  ├─ 检测浊度
  └─ 判断是否继续漂洗
  ↓
脱水阶段
  ├─ 打开排水阀
  ├─ 等待水排尽
  ├─ 启动脱水电机
  ├─ 逐步加速到最高转速
  ├─ 脱水设定时间
  └─ 逐步减速停止
  ↓
完成
  ├─ 蜂鸣器提示
  ├─ 显示完成信息
  └─ 等待取衣
```

## 4. 核心算法设计

### 4.1 自适应洗涤算法

```c
// 根据衣物重量调整洗涤时间
wash_time = base_time + (weight - base_weight) * time_per_kg;

// 根据衣物重量调整用水量
water_volume = base_volume * (weight / base_weight);

// 根据浊度调整漂洗次数
if (turbidity > threshold_high) {
    rinse_count = max_rinse_count;  // 最多次数
} else if (turbidity > threshold_mid) {
    rinse_count = mid_rinse_count;  // 中等次数
} else {
    rinse_count = min_rinse_count;  // 最少次数
}
```

### 4.2 温度控制算法

```c
// PID控制加热
if (current_temp < target_temp) {
    error = target_temp - current_temp;
    integral += error * dt;
    derivative = (error - prev_error) / dt;
    
    output = Kp * error + Ki * integral + Kd * derivative;
    
    if (output > 0) {
        enable_heater();
    } else {
        disable_heater();
    }
}
```

### 4.3 安全检测算法

```c
// 多层安全检测
if (!door_closed) {
    emergency_stop();  // 门未关
    return;
}

if (water_level_high) {
    close_inlet_valve();  // 水位过高
}

if (water_level_low && in_wash_stage) {
    trigger_alarm();  // 漏水报警
}

if (motor_current > over_load_threshold) {
    motor_stop();  // 过载停止
}

if (temp_high > over_temp_threshold) {
    heater_stop();  // 过温停止
}
```

```c
typedef struct {
    uint8_t mode;              // 工作模式
    uint8_t state;             // 当前状态
```

**命令列表**
| CMD | 功能 | 数据 |
|-----|------|------|
