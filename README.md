# 智能洗衣机系统

基于STM32F103C8T6的完整嵌入式解决方案，包含硬件设计、固件开发、上位机软件和蓝牙APP。

## 🎯 核心设计目标

- ✅ **全自动**：完整的洗涤程序自动执行
- ✅ **自适应**：根据衣物特性动态调节参数
- ✅ **高安全**：多重安全保护机制
- ✅ **易操作**：友好的人机交互界面

## 📋 主要功能

### 核心功能模块
1. **多模式洗涤**
   - 标准洗涤模式
   - 快速洗涤模式
   - 精细洗涤模式
   - 强力洗涤模式
   - 自定义模式

2. **智能传感与控制**
   - 水位自动检测与控制
   - 水温实时监测与调节
   - 衣物重量感知
   - 门开关安全检测
   - 浊度智能检测

3. **执行器控制**
   - 进水阀电磁控制
   - 排水阀电磁控制
   - 洗涤电机控制
   - 脱水电机控制
   - 加热管温度控制

4. **人机交互**
   - LCD/OLED实时显示
   - 按键输入控制
   - 蜂鸣器反馈
   - 状态指示灯

5. **数据通信**
   - 串口数据传输
   - 蓝牙APP远程监控
   - 历史数据存储
   - 实时参数查询

### 扩展功能
- 🔵 **蓝牙模块**：手机APP远程控制与监控
- 💧 **浊度传感器**：自适应漂洗次数
- 🌊 **水浸传感器**：漏水报警保护
- 💾 **数据存储**：EEPROM/SD卡历史记录
- 👶 **童锁功能**：儿童安全保护

## ⚡ 快速开始

### 硬件连接
详见 `Documentation/接线图.md`

### 固件编译与烧录
1. 打开Keil MDK
2. 打开工程文件 `Firmware/Project/WashingMachine.uvprojx`
3. 编译项目
4. 通过ST-Link或USB烧录到STM32

### Proteus仿真
1. 打开 `Hardware/Proteus/WashingMachine.pdsprj`
2. 运行仿真
3. 观察各模块动作

### PC上位机
1. 安装Python环境
2. 运行 `Software/PC_Monitor/main.py`
3. 选择串口连接
4. 实时监控系统状态

### 蓝牙APP
1. 安装蓝牙APP（Android/iOS）
2. 扫描配对HC-05模块
3. 远程监控与控制

## 📊 工作模式

### 标准模式
- 进水 → 洗涤 → 漂洗(3次) → 脱水 → 完成
- 洗涤时间：30分钟
- 水温：常温

### 快速模式
- 进水 → 洗涤 → 漂洗(1次) → 脱水 → 完成
- 洗涤时间：15分钟
- 水温：常温

### 精细模式
- 进水 → 轻柔洗涤 → 漂洗(5次) → 脱水 → 完成
- 洗涤时间：40分钟
- 水温：30℃

### 强力模式
- 进水 → 强力洗涤 → 漂洗(3次) → 脱水 → 完成
- 洗涤时间：45分钟
- 水温：60℃

### 自定义模式
- 用户可自定义所有参数
- 支持保存最多5个自定义模式

## 🔐 安全保护机制

✅ 门开关保护 - 门打开时立即停止运行
✅ 水位过高保护 - 自动停止进水
✅ 水位过低保护 - 检测漏水并报警
✅ 温度过高保护 - 加热超温自动断电
✅ 电机过载保护 - 检测异常电流
✅ 漏电保护 - 漏电断路器
✅ 童锁功能 - 防止儿童误操作
✅ 故障自诊断 - 传感器故障检测

## 📡 通信协议

### 串口通信
- 波特率：9600 bps
- 数据格式：JSON格式
- 发送周期：1秒

### 蓝牙通信
- 协议：SPP（Serial Port Profile）
- 波特率：9600 bps
- 数据包格式：[HEADER][CMD][DATA][CHECKSUM]

详见 `Documentation/通信协议.md`
